# Происхождение временной графики

Все перечисленные материалы созданы специально в рамках разработки Creative Factory 23–26 октября 2026 года. Изображения, карты, примеры и код WorkAdventure или сторонние art packs не использованы.

| Материал                     | Источник                                                               | Способ создания / замены                                                                                   |
| ---------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Tiled-карта                  | `maps/factory.tmj`, `maps/workshops.json`                              | Собственная ортогональная планировка; первоначально создана нашим `author-map.ts`                          |
| Плитки пола и стен           | `maps/placeholder-tiles.svg`                                           | Оригинальные SVG-прямоугольники, линии и узор; заменить собственным tileset с обновлением content provider |
| Персонаж и предметы          | `../apps/web/src/game/placeholderArt.ts`                               | Оригинальная процедурная Canvas 2D-графика, не основанная на чужих изображениях                            |
| Внешность и кадры            | `avatars/catalog.json`                                                 | Наши ID частей, палитра и последовательности кадров                                                        |
| Знак интерфейса              | `../apps/web/public/favicon.svg`, `../apps/web/src/App.tsx`            | Собственная простая геометрия завода                                                                       |
| Варианты персонажа           | `../apps/web/src/avatar/art.ts`                                        | Собственная Canvas-графика: 2 тела, 3 причёски, 3 вида одежды, наушники; общая для предпросмотра и игры    |
| Иллюстрация главной и иконки | `../apps/web/src/pages/HomePage.tsx`, `../apps/web/src/components.tsx` | Оригинальные SVG-геометрия и знак, без сторонних изображений                                               |

Реестр контрольных сумм исходников графики и карты создаётся `npm run content:build` в `apps/web/public/content/provenance.json`. Это позволяет связать собранный результат с источниками. Настоящие сторонние ассеты добавлять только с отдельной записью автора, URL/договора, версии, hash, разрешённых способов использования и обязательной атрибуции. Лицензию нашего проекта этот технический этап автоматически не назначает.
