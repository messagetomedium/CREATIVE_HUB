# Происхождение временной графики

Все перечисленные материалы созданы специально в рамках разработки Creative Factory 23–28 октября 2026 года. Изображения, карты, примеры и код WorkAdventure, Stardew Valley или сторонние art packs не использованы.

| Материал                     | Источник                                                               | Способ создания / замены                                                                                                                              |
| ---------------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tiled-карта                  | `maps/factory.tmj`, `maps/workshops.json`                              | Собственная ортогональная планировка; первоначально создана нашим `author-map.ts`                                                                     |
| Плитки пола и стен           | `maps/placeholder-tiles.svg`                                           | Оригинальные SVG-прямоугольники, линии и узор; заменить собственным tileset с обновлением content provider                                            |
| Персонаж и предметы          | `../apps/web/src/game/placeholderArt.ts`                               | Оригинальная процедурная Canvas 2D-графика, не основанная на чужих изображениях                                                                       |
| Внешность и кадры            | `avatars/catalog.json`                                                 | Наши ID частей, палитра и последовательности кадров                                                                                                   |
| Знак интерфейса              | `../apps/web/public/favicon.svg`, `../apps/web/src/App.tsx`            | Собственная простая геометрия завода                                                                                                                  |
| Варианты персонажа           | `../apps/web/src/avatar/art.ts`                                        | Собственная Canvas-графика: одна взрослая анатомия, 3 параметрические комплекции, временные варианты одежды, наушники; общая для предпросмотра и игры |
| Иллюстрация главной и иконки | `../apps/web/src/pages/HomePage.tsx`, `../apps/web/src/components.tsx` | Оригинальные SVG-геометрия и знак, без сторонних изображений                                                                                          |

Графический шаг 27 октября: вертикальные 3/4 формы персонажа — `../apps/web/src/avatar/art.ts`; десять простых форм предметов и четыре сегмента фасада стены — `../apps/web/src/game/sceneArt.ts`, раскладка — `art/scene-art.json`. `art/reference/*-blockout.png` экспортированы из этого же собственного кода через `scripts/export-art-reference.mjs`; это эталоны для художника, не загружаемые игрой. `art/avatar-layered.example.json` содержит только пример имён/слоёв, без чужих ресурсов. Настоящие PNG-замены пока не добавлялись.

Реестр контрольных сумм исходников графики и карты создаётся `npm run content:build` в `apps/web/public/content/provenance.json`. Это позволяет связать собранный результат с источниками. Настоящие сторонние ассеты добавлять только с отдельной записью автора, URL/договора, версии, hash, разрешённых способов использования и обязательной атрибуции. Лицензию нашего проекта этот технический этап автоматически не назначает.

Модульные женские причёски: `content/avatars/modular/hair-indexed.png` — оригинальная AI-assisted интерпретация предоставленного референса, 4 стиля × 4 вида. Исходная генерация сохранена в `content/art/source/hair-test-original.png`; нормализованный игровой файл индексирован в 5 нейтральных уровней. Не использованы ассеты WorkAdventure. Тело и временная одежда рисуются оригинальным кодом рига.

Графический пайплайн 28 октября: `CHARACTER/` — неизменяемые художественные оригиналы; `content/art/character-<hash>.png` и `character-thumb-<hash>.png` — технические производные. Их source hash/режимы/порядок частей указаны в `content/avatars/modular/import-manifest.json`. Новые художественные коллекции этим этапом не создавались. Процедурное тело перерасчитано в 96×128 с нативным контуром 1 px; старые тестовые волосы проходят отдельный совместимый адаптер. PNG.js используется только как MIT-инструмент импорта/проверок, в браузер не включается.
