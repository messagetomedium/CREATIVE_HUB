# Простые имена и ITEMS.md

**`category_template_symmetry_number.png`** — маленькие латинские буквы, номер из двух цифр. Примеры и ссылки на все точные PNG — в [таблице](README.md).

- `pants_high_full_01.png`, `skirt_low_full_02.png`, `shorts_high_full_03.png` → CHARACTER/bottoms. Один цельный лист вещи. Посадка high/low обязательна. Это варианты общих слотов низа, без изменения редактора.
- `hair_long_full_01.png`, `hair_short_pair_02.png` → CHARACTER/hair. Цельная причёска, включая нужные перекрытия; не отдельные front/back файлы.
- `hat_detail_sym1_01.png` → hats; `accessory_detail_sym2_01.png` / `accessory_detail_full_02.png` → jewelry. Один тип DETAILS для верхних деталей, различаются только режим и папка слота.
- `eyes_basic_front_01.png`, `mouth_basic_front_01.png`, `face_detail_front_01.png` → eyes, mouth, face_features. Только фронтальная графика; профили создаёт код.
- `shoes_basic_pair_01.png` → footwear. Один ботинок: фронт, правый бок, спина.
- `top_body_pair_01.png`, `top_sleeve_pair_01.png`, необязательный `top_glove_pair_01.png` → tops. Один номер для одного комплекта верха. Для безрукавки достаточно body.
- `body_torso_full_01.png`, `body_arm_full_01.png`, `body_leg_full_01.png` → body_features. Только эффект на части тела, без повторной кожи.
- `item_hand_full_01.png` → specials. Предмет на правой кисти по умолчанию, без самой ладони.

Лицевые особенности соответствуют редактору: 01 веснушки, 02 родинки, 03 покраснения, 04 тени под глазами, 05 румянец, 06 переносица. Особенно важно не менять номер переносицы: для неё используется центральная профильная проекция.

`full`: S/E/N/W. `pair`: S/E/N, W отражается из E. `sym1`: один S для всех четырёх направлений. `sym2`: S/E, W отражённый E, N повторяет S. Для отличающегося N выбрать full. `front`: один S, N невидим, E/W — техническая адаптация соответствующих половин лица.

Для намеренно разных каталогов волос допустим `hair_long_female_full_01.png` / `hair_long_male_full_01.png`. Без female/male предмет универсальный: отдельные копии по полу не требуются. Не занимать один слот одновременно универсальным и гендерным предметом.

Неперекрашиваемую фурнитуру можно отдать дополнительным PNG с тем же типом/номером и словом `fixed`: `top_body_fixed_pair_01.png`, `pants_high_fixed_full_01.png`. Маска остаётся в технических индексах, fixed-слой — цветной RGBA. Номер и обязательные параметры нельзя опускать у низа; для eyes/mouth допустимы краткие `eyes_basic_01.png`/`mouth_basic_01.png` (по умолчанию front). Лучше использовать явные имена из таблицы.

## ITEMS.md — только название или исключение

| Файл/ID                      | Название | Симметрия | Крепление | Наложение | Материал      | Особенности                    |
| ---------------------------- | -------- | --------- | --------- | --------- | ------------- | ------------------------------ |
| accessory_detail_sym2_01.png | Наушники | sym2      | голова    | спереди   | фиксированный | Задний вид совпадает с фронтом |

Для стандартной вещи строка не нужна. Ключ — точное имя PNG; общий ID также поддерживается. Имя, симметрия и строка не должны противоречить друг другу. Пустые клетки используют стандартные правила. Крепления: голова/корпус/таз, левая/правая рука/кисть/нога/стопа; нужно выбрать подходящий шаблон, произвольное крепление не меняет холст. Для цельной причёски и низа проходы/части определяются по зонам и типу; не пытайтесь вручную заменить их метаданными наложения.

Материалы: кожа, волосы, верх, низ, обувь, шапка, украшение, предмет или fixed/фиксированный. По умолчанию материал известен из категории; глаза и рот fixed. Наложение для обычной детали — спереди/front или сзади/back. Особенности — пояснение для визуального просмотра, а не JSON и не команды движку.

Импорт не перезаписывает оригинал. Критическая ошибка появляется в DEBUG_REPORT.md; последняя принятая версия остаётся рабочей. Исправить PNG/ITEMS.md и повторить `npm run character:import`. Старый внутренний формат имён с двойными подчёркиваниями читается для совместимости, но новые работы сдавайте по этой системе.
