# Имена и размещение готовых PNG

Формат **category_template_symmetry_01.png**, маленькие латинские буквы. Номер — слот редактора, не номер анимационного кадра. Точные размеры и подложки — [в таблице](README.md).

| Папка CHARACTER | Пример имени                                    | Что в файле                                                          |
| --------------- | ----------------------------------------------- | -------------------------------------------------------------------- |
| hair            | `hair_long_female_full_01.png`                  | Одна женская причёска, 4 статичных вида                              |
| hair            | `hair_short_male_pair_01.png`                   | Одна симметричная мужская причёска, 3 вида                           |
| eyes            | `eyes_basic_front_01.png`                       | Один набор двух глаз                                                 |
| mouth           | `mouth_basic_front_01.png`                      | Один рот                                                             |
| face_features   | `face_detail_front_01.png`                      | Один лицевой эффект                                                  |
| body_features   | `body_torso_full_01.png`                        | Эффект на корпусе                                                    |
| body_features   | `body_arm_full_01.png` / `body_leg_full_01.png` | Дополнительные части того же эффекта, только если нужны              |
| tops            | `top_body_full_01.png`                          | Корпус одного верха                                                  |
| tops            | `top_sleeve_full_01.png`                        | Один рукав того же верха                                             |
| tops            | `top_glove_pair_01.png`                         | Необязательная перчатка того же верха                                |
| tops            | `top_body_female_full_01.png`                   | Альтернативная женская посадка корпуса, не второй слой поверх общего |
| bottoms         | `pants_high_full_01.png`                        | Цельные брюки с высоким поясом                                       |
| bottoms         | `skirt_low_full_02.png`                         | Цельная юбка без отдельного высокого пояса                           |
| bottoms         | `shorts_high_pair_03.png`                       | Цельные симметричные шорты                                           |
| footwear        | `shoes_basic_pair_01.png`                       | Один ботинок S/E/N                                                   |
| hats            | `hat_detail_full_01.png`                        | Шапка S/E/N/W                                                        |
| jewelry         | `accessory_detail_full_01.png`                  | Украшение головы/шеи S/E/N/W                                         |
| specials        | `item_hand_full_01.png`                         | Предмет на правой кисти                                              |

`full` = S/E/N/W; `pair` = S/E/N с отражением E для W; `front` = один S лица. `sym1` = один S для всех направлений, `sym2` = S/E, N повторяет S, W отражает E. Последние два режима только для действительно одинаковых видов, не для обычной объёмной шапки. Подходящий режим выбирается один раз: не сдавать одновременно full и pair одной вещи.

Номер 01…06 во всех категориях, 01…12 только у особенностей тела. Pants/skirt/shorts занимают **общие шесть слотов низа**. Не называть разные виды низа одним номером. Части одного верха/эффекта, наоборот, имеют один общий номер.

Для волос каталоги male/female независимы: каждый имеет 01…06. Универсальная вещь не требует копии на каждый пол/телосложение. Если женский и мужской дизайн различаются, добавить female/male к именам всего соответствующего комплекта; одинаковую графику можно переиспользовать при подключении. Универсальный вариант и гендерные альтернативы нельзя молча смешивать в одном слоте.

Неперекрашиваемая фурнитура — дополнительный прозрачный fixed-слой с той же посадкой: например `top_body_fixed_full_01.png` или `pants_high_fixed_full_01.png`. Он не содержит повторную маску ткани. Сначала проверить один такой комплект, затем масштабировать производство.

## ITEMS.md

Обычному файлу достаточно правильного имени. В ITEMS.md папки записать название дизайна и только необходимые исключения: асимметрия рук, особый проход слоёв, неперекрашиваемый материал, желаемое крепление. Указать точное имя PNG. Художник не пишет JSON, риг, матрицу анимации или параметры физики.

| Файл/ID                      | Название | Симметрия | Крепление | Наложение | Материал      | Особенности                     |
| ---------------------------- | -------- | --------- | --------- | --------- | ------------- | ------------------------------- |
| accessory_detail_full_01.png | Наушники | full      | голова    | спереди   | фиксированный | Все четыре вида самостоятельные |

Смена крепления в строке не меняет геометрию выбранного холста. Если нужен браслет, длинное ожерелье, разные рукава или особая юбка — приложить пояснение к одному тестовому дизайну. Не угадывать другой центр и не заказывать полную коллекцию до проверки.

Старые имена с двойными подчёркиваниями относятся к прежнему импортёру. Новый утверждённый комплект имеет свою версию; порядок безопасного подключения описан в [DELIVERY.md](DELIVERY.md).
