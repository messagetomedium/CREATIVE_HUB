# Сдача и проверка

[Пять макетов и имена](../README.md) · [Технические правила](ART_RULES.md) · [Комплект ZIP](CREATIVE_FACTORY_ARTIST_KIT.zip).

1. Открыть один TEMPLATE, рисовать цельный предмет на новом слое. Подложку скрыть; экспортировать только рисунок в полный PNG на прозрачности.
2. Проверить порядок S/E/N/W (обувь S/E/N), контур 2 px, палитру и прозрачный пиксель по границам клеток. Заполнить обязательные виды; для глаз/рта/лица только S.
3. Сохранить под простым именем из таблицы, номер 01…06, положить в указанную папку CHARACTER. Обычной вещи не нужны дополнительные файлы. ITEMS.md и техническая маска только для исключений.
4. Попросить Codex импортировать CHARACTER. **`npm run character:import` поддерживает этот комплект**: ракурсы по alpha, проекцию лица, слои волос, корпус/рукава/манжеты цельного верха, пояс и штанины низа, цельную юбку и обувь.
5. Проверить один образ: hair + top + bottom/skirt + shoes, затем запускать серийную отрисовку. Исходник не перезаписывается; непомещающаяся после подгонки или ошибочная замена сохраняет последний рабочий вариант и получает понятную запись в DEBUG_REPORT.md.

## Что проверять в редакторе

Все четыре направления; оба пола; очень худое/худое/среднее/плотное тело; ожидание/ходьба; швы у шеи, плеч, кистей и пояса; кожу под короткими штанинами; пятки и центр обуви. Голова/волосы при ходьбе не должны менять высоту или масштаб. После сохранения и reload должен восстановиться тот же вариант.

Утверждённые тело/анимация/UI `01432c7` не подстраиваются под ошибку графики. Подгонка вещи выполняется один раз перед запеканием, не на каждом кадре прогулки. Ракурсы с собственным W/N сохраняются, пропущенные достраиваются только по явным правилам alpha. Существующие сохранения и legacy-ассеты не удаляются.

## Честные границы автоматики

Автомат не восстанавливает невидимую ткань и не угадывает фасон по изображению. Обычные вещи используют видимые технические зоны; сложные пряди и пересечения рукавов требуют необязательной маски. Полностью прозрачная ячейка — осознанное разрешение достроить вид; для отдельного затылка шапки нужно нарисовать N. TOP/HAIR/BOTTOM требуют настоящего N.

Профильная дальняя рука при ходьбе остаётся скрытой по утверждённой анимации. Не заказывать для неё отдельные фазы. Юбка — цельный модуль без симуляции ткани. Особенности тела и предметы в руках не производятся этим комплектом, но существующие поля редактора/сохранения сохранены.

Контроль комплекта: `npm run art:build`, `npm run art:check`. Генератор экспортирует ровно пять TEMPLATE и утверждённые эталоны, без EMPTY/вариантов по полу/симметрии. Проверка исходных SHA-256 не позволяет незаметно изменить утверждённую анатомию и движение. Реальная проверка художественного качества начинается с первой иллюстрации; тестовые геометрические картинки не считаются принятым художественным набором.
