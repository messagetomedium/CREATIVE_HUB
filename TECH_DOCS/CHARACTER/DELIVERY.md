# Сдача и проверка графики

Комплект `approved-editor-2026-10-29` построен по утверждённому редактору `01432c7`. Скачать можно целиком из [CREATIVE_FACTORY_ARTIST_KIT.zip](CREATIVE_FACTORY_ARTIST_KIT.zip). Начать с README внутри TECH_DOCS. Архив содержит документы, прозрачные холсты, подложки и папки сдачи; исходный код приложения художнику не нужен.

## Действия художника

1. Выбрать нужный тип, посадку и режим в [таблице](README.md); рисовать в исходном размере на слое над TEMPLATE.
2. Оставить полные поля клеток и прозрачный фон, скрыть подложку/сетку/крест. Проверить контур 2 px, отсутствие сглаживания и правильный порядок S/E/N/W или S/E/N.
3. Экспортировать готовую графику в PNG. У маски ткани/волос — техническая палитра; у fixed — нужные цвета, у кожного эффекта допускается полупрозрачность.
4. Назвать по [FILE_NAMING](FILE_NAMING.md), положить в нужную папку CHARACTER. Особые пожелания записать в её ITEMS.md. Сначала один комплект из пяти PNG, затем серия после проверки.
5. Написать разработчику: **«Подключи тестовый комплект CHARACTER к утверждённому персонажу версии 01432c7, редактор и тело не менять»**.

## Приёмка первого комплекта

- Масштаб 100%: нативные пиксели, контур 2 px, поля и прозрачность сохранены.
- S/E/N/W: перед/спина не перепутаны, W не отражён для асимметричной вещи, волосы не прыгают относительно головы.
- Ожидание/ходьба: воротник не отрывается от шеи, плечи не образуют отверстий, кулачок закрывает нижний стык рукава, поднятая нога не открывает шов низа.
- Женщина/мужчина, четыре комплекции: нет новой формы тела, обувь сохраняет размер, S/N по центру голени, профильная пятка на задней линии голени.
- Палитры: ткань меняет цвет, фурнитура fixed сохраняет цвет, эффекты кожи не рисуют второе тело.
- Каталог/сохранение: нужный слот, правильный пол волос, сохранение и восстановление после reload.

## Текущее состояние подключения — для разработчика

**Новый художественный комплект готов для рисования, но прежняя команда `character:import` ещё не является импортёром этого утверждённого рига.** В этом изменении обновляются документы и подложки, приложение не изменяется. Нельзя объявлять новый PNG автоматически подключённым или менять редактор под старый импортёр.

Старый импортёр/адаптер рассчитан на прежний контур 1 px, плечи/талии, рукава 24×32 с опорой (12,4), канонические длины 20/24 и старое распределение штанин. Новые рукава/накладки руки — 24×40 с опорой (12,8), длины рига 26/26, контур 2 px, новые опоры корпуса/кисти/стоп и анатомический порядок N. Даже совпадение размеров файла не доказывает правильную посадку.

Перед первым подключением новых PNG адаптировать **внебраузерную подготовку и подгонку импортированных слоёв** к новому контракту, не менять утверждённые UI/силуэт/движение. Проверить source-to-module соответствие: верх к (48,72), рукав к плечу y=64, кисть к y=86 с центром кулачка +4 px, нога к y=84/голеностопу 110, N с противоположным экранным порядком анатомических ног, профильная пятка по ширине голени. Сохранить оригиналы, RLS/IDs слотов и последнюю рабочую версию при ошибке импорта. Фазы одежды запекать по существующим 125/175/125/175 мс, не вводить вращение/сгиб/новую походку.

`npm run art:build` пересоздаёт только этот художественный комплект из утверждённого редактора; `npm run art:check` проверяет PNG, размеры, прозрачность, опоры и сохранность утверждённых исходных файлов. Эти команды не импортируют художнические PNG и не заменяют визуальную приёмку. Следующий шаг после тестовой поставки — проверенное подключение графики; перенос утверждённого тела на завод отдельно и сейчас не выполняется.
