# Как рисовать по шаблонам

## Цвет и экспорт

| HEX       | Назначение                                                         |
| --------- | ------------------------------------------------------------------ |
| `#202020` | Внешний контур **1 исходный пиксель**, в игре постоянный `#352b35` |
| `#505050` | Глубокая тень                                                      |
| `#808080` | Полутень                                                           |
| `#b8b8b8` | Выбранный основной цвет                                            |
| `#f0f0f0` | Свет                                                               |

[Палитра PNG](COLORS.png). Для обычной маски alpha 0/255, без сглаживания/шума и обводки каждого внутреннего перехода. Для кожных/лицевых эффектов допустима промежуточная alpha; цвет считается относительно кожи. Глаза/рот и fixed-декор могут быть цветными RGBA. Неверные цвета не нормализуются молча. Не нужны версии на каждый цвет, пол и телосложение.

TEMPLATE — подложка с каноническим телом, сеткой, опорой и зонами. Создать новый слой, нарисовать, **скрыть TEMPLATE**, экспортировать только рисунок PNG. EMPTY — полностью прозрачный холст тех же размеров. Не обрезать поля и не двигать рисунок относительно опоры. Оставлять 1 прозрачный пиксель до края клетки; дополнительные ограничения цветных зон также обязательны. Никакие PSD/ORA/Aseprite/JSON для сдачи не нужны.

## Причёска целиком

Шаблоны short/long показывают голову, шею, корпус и плечи/руки. Художник рисует **одну цельную причёску на ракурс**, с прозрачным окном лица. Не включать кожу/глаза/рот/уши в рисунок волос.

**Розовые области — передний слой, бирюзовые — задний.** Код делит изображение строго по этим зонам, не пытается распознать дизайн. На голове волосы идут поверх головы; во фронте ниже подбородка передние пряди рисуются в розовых боковых полосах, центральная бирюзовая область уходит за корпус. В правом профиле передняя область справа, задняя слева; в левом наоборот. Со спины вся видимая причёска накладывается поверх спины: иначе тело заслонило бы волосы.

Пряди, косы или чёлка, которым нужно перекрывать лицо/шею/плечо/грудь, должны находиться в розовой зоне. Задняя масса — в бирюзовой. Если конкретный дизайн нельзя выразить этими зонами, сначала передайте один тестовый вариант и пояснение: произвольную скрытую глубину из единственного PNG восстановить однозначно невозможно. Код не перерисует его незаметно. Передний и задний слои вручную сдавать не требуется.

Пучок/макушка должны помещаться внутри клетки. Для длинных волос используется long, не растяжение short. Четыре вида full: S/E/N/W; три pair: S/E/N. В E/W видно профиль, не затылочную картинку. Асимметрия требует full.

## Низ целиком

Выберите pants_high/low, skirt_high/low или shorts_high/low. **Рисовать цельные брюки, юбку или шорты на одном листе. Не вырезать пояс, таз или штанины вручную.**

High: верхняя поясная область между верхней и второй линиями шаблона относится к отдельному верхнему модулю. Ниже — основная нижняя часть. Low: выше второй линии не рисовать, отдельной верхней полосы нет, вся вещь относится к нижнему модулю. High без нарисованного верхнего пояса — ошибка типа; выбрать low.

У брюк/шорт ниже линии разделения код выделяет две штанины по размеченным зонам. Во фронте/спине рисуйте обе ноги как часть цельной вещи; **в профиле — одну видимую штанину**, скрытую дальнюю программа получает из неё. Не выходить за боковые границы этих зон: иначе безопасный разбор невозможен. Верх/пояс закрывает стык, без поперечных тёмных швов на скрытом срезе. У шорт есть отдельная линия допустимого подола.

Юбка ниже пояса остаётся одним цельным модулем, закрывающим ноги; она не разрезается на две штанины. High даёт пояс + цельную юбку, low — только цельную юбку. Длину, разрез и фасон задаёт художник внутри допустимой области. Физика ткани сейчас не добавляется.

## Лицо и единые details

- Глаза — два глаза только во фронте. Для E берётся правый глаз исходника, для W левый, каждый переносится на профильную позицию. Разный цвет/форма глаз сохраняются; второй глаз в профиль не добавляется.
- Рот — один фронтальный рисунок. Код берёт соответствующую половину и переносит к профилю, сохраняя хотя бы один пиксель маленького рта. Боковой рот вручную не нужен.
- Лицевая накладка — один фронтальный слой на голове/шее, без кожи. В E/W берётся соответствующая половина с адаптацией положения, у переносицы — центральная область. N пустой. Проверить в игре: необычная асимметрия/узор может требовать отдельного уточнения, автоматическая проекция не является 3D-реконструкцией лица.
- Верхние детали используют один DETAILS: sym1 (1 вид для всех), sym2 (фронт+бок, N=фронт, W=отражённый E), full (все четыре). Шапке/украшению/аксессуару не нужны разные шаблоны. Лицевая накладка front рисуется на той же подложке, что details sym1, но импортируется как лицевая маска.

## Обувь, кисти и шея

Обувь: рисуется **один цельный ботинок** в трёх видах S/E/N, не пара и не набор носок/пятка/подошва. В шаблоне показаны одна стопа и голеностоп, есть место для длинного бокового носка. Второй ботинок отражается во фронте/спине, для противоположного профиля отражается E. Коллизия персонажа от размера ботинка не меняется.

Рукав не содержит кисть. Необязательная перчатка/манжета — отдельная деталь; пальцы не анимировать. Для pair симметричная часть переиспользуется/отражается на второй конечности; для действительно разных левой и правой частей указать отдельные крепления в ITEMS.md.

**Каноническая шея создаётся программно:** за головой и над корпусом, тёмный лайн слева/справа, снизу лайна нет. Нижняя заливка плавно соединяется с цветом корпуса. Шея уже присутствует в нужных подложках, её не дорисовывать в волосах, лице, одежде и аксессуарах.

После первого импорта проверить исходный масштаб, увеличенный просмотр, четыре направления, idle/walk и три комплекции. Оригинальный PNG остаётся неизменным; рабочие слои, отражения и A24 создаёт код.
