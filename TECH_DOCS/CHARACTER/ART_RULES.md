# Как рисовать пятью макетами

[Короткая инструкция и все имена](../README.md) · [Размеры пяти PNG](README.md) · [Утверждённое тело](BODY_STANDARD.md) · [Сдача](DELIVERY.md).

Внутри каждой клетки — полупрозрачный эталон и технические зоны. Рисовать на новом прозрачном слое, подложку/сетку/подписи скрыть. Не обрезать поля, не масштабировать PNG, не применять сглаживание. Оставить 1 прозрачный пиксель у края каждой клетки. Кадры ходьбы, варианты цветов и четыре телосложения вручную не рисовать.

## Цвет

| HEX       | Назначение                                                |
| --------- | --------------------------------------------------------- |
| `#202020` | Внешний контур **2 исходных px**, после окраски `#352b35` |
| `#505050` | Глубокая тень                                             |
| `#808080` | Полутень                                                  |
| `#b8b8b8` | Выбранный пользователем основной цвет                     |
| `#f0f0f0` | Свет                                                      |

Обычные маски волос/ткани/шапок/украшений — эти пять серых индексов, alpha 0/255. Глаза/рот — цветные RGBA. Для неперекрашиваемого дизайна можно указать «Материал: fixed» в ITEMS.md. Лицевые эффекты допускают промежуточную alpha, обычная одежда — нет. Не рисовать кожу в вещи; видимую голую кожу создаёт персонаж.

Контур 2 px относится к внешней границе. Скрытые стыки под плечом и над штаниной не обводить поперёк: части должны иметь цветовое перекрытие. Декоративные швы и складки — по дизайну, не обводить каждый тональный переход.

## HAIR — одна цельная причёска

Клетка **96×112**, опора (48,34), четыре клетки S/E/N/W, PNG **96×448**. Длина любая внутри холста; отдельного короткого макета нет. Нужны S/E/N, W можно оставить пустым только при симметрии профилей. Рисовать профиль в E/W, не затылок. Не включать голову, кожу, уши, глаза или шею в сам рисунок волос.

Подложка показывает голову, уши, шею, плечи, верх корпуса и руки. Розовое — передний слой, бирюзовое — задний. На голове y<54 всё идёт поверх головы; окно лица оставляет художник. Ниже y=54: S — передние полосы x=28…39 и 56…67, остальное за корпусом; E — перед x≥48; W — перед x<48. В N видимая масса поверх спины. Программа готовит два внутренних слоя из цельного PNG; анимация не масштабирует волосы.

Для сложной пряди поверх груди/плеча/лица можно добавить **необязательную маску** того же полного размера: красный `#ff0000` = перед, синий `#0000ff` = зад. Каждый видимый пиксель вещи должен быть помечен непрозрачной меткой. В ITEMS.md указать имя маски. Маска уточняет глубину, не заменяет художественную графику и не меняет её цвет.

## HEAD — один холст для всего на голове

Клетка **64×64**, опора головы (32,32), PNG **64×256**, S/E/N/W. На подложке только голова и шея. Глаза, рот, лицевой эффект, шапка и аксессуар используют один и тот же макет; создаются отдельные PNG соответствующих категорий, а не один объединённый файл лица.

Для eyes/mouth/face заполнять **только S**. Глаза — оба глаза, ориентиры (22,30) и (38,30), примерно 4×8. Рот около (30,44). Профили создаются из соответствующих половин, N пустой. Отдельные кадры моргания/речи не нужны. Особенности лица: 01 веснушки, 02 родинки, 03 покраснения, 04 синяки под глазами, 05 румянец, 06 переносица. Не включать повторную кожу.

Для hat/accessory прозрачность ячеек — сознательное указание достраивания:

| Заполнены | N                                              | W           | E       |
| --------- | ---------------------------------------------- | ----------- | ------- |
| S         | Копия S                                        | Копия S     | Копия S |
| S/E       | Копия S                                        | Отражение E | Свой E  |
| S/E/N     | Свой N                                         | Отражение E | Свой E  |
| S/E/W     | Горизонтальное отражение S; опционально N=copy | Свой W      | Свой E  |
| S/E/N/W   | Свой N                                         | Свой W      | Свой E  |

Другие сочетания — ошибка. Виды не сравниваются по похожести, отсутствующим считается только полностью прозрачная ячейка. Для объёмной шапки с отдельным затылком нарисовать N: программа не может угадать его по переду. Для деталей на груди/кисти HEAD не использовать: он закреплён на голове и верхней шее.

## TOP — вся вещь с рукавами

Клетка **96×112**, опора корпуса (48,72), PNG **96×448**. Нужны S/E/N, W необязателен при симметрии. Рисовать цельную футболку, рубашку, свитер, куртку с **обоими рукавами спереди/сзади** и одним видимым рукавом в профиль. Безрукавка просто не содержит нарисованных рукавов. Если в наружных зонах рук/кистей нет непрозрачных пикселей, соответствующие рукава/манжеты не создаются из края корпуса. Перчатки/манжеты при необходимости входят в тот же рисунок.

Ориентиры полного кадра: корпус y=58…91, плечевой узел y=64, низ прямой руки y=90, кистевой узел y=86, центр кулачка y=90. Выше y=50 зона головы, обычная одежда там запрещена. Стандартные границы корпуса около x=33/63; в профиле учитывается собственная посадка ближней руки. Скрытые стыки должны перекрываться цветом. При разборе копируются исходные пиксели, в стыках — технологическое перекрытие 2 px; графика не перекрашивается и не дорисовывается импортёром.

Корпус, оба рукава и при наличии манжеты/перчатки выделяет программа. Нельзя подписывать отдельные файлы body/sleeve/glove. Рисовать базовый дизайн по среднему телу; подгонка на мужчину/женщину и все четыре комплекции выполняется автоматически. Для специфической исходной женской посадки — необязательное «Посадка: female» в ITEMS.md, без отдельного макета. Все исходные опоры остаются теми же.

Обычный силуэт разделяется по точным зонам плеч и кистей, а не по распознаванию рисунка. Для сложного фасона — дополнительная техническая маска такого же полного размера:

| Цвет маски | Модуль                |
| ---------- | --------------------- |
| `#ff0000`  | Корпус                |
| `#00ff00`  | Левая рука персонажа  |
| `#0000ff`  | Правая рука персонажа |
| `#00ffff`  | Левая кисть/манжета   |
| `#ff00ff`  | Правая кисть/манжета  |

В N анатомические стороны меняются местами на рисунке. Меткой покрыть каждый видимый пиксель вещи; прозрачные пиксели маски вне рисунка не важны. На соприкасающихся зонах программа создаёт перекрытия из уже нарисованной графики, не выдумывая скрытую ткань. В профиль художник рисует видимую конечность, скрытая готовится из неё. Необычные конструкции сначала проверить одним образцом.

## BOTTOM — брюки, шорты, капри и юбки

Клетка **80×64**, опора таза (40,20), PNG **80×256**, S/E/N/W. Нужны S/E/N, W по симметрии. `bottom_01.png` означает любую вещь с двумя штанинами: длина определяется нарисованными пикселями. `skirt_01.png` — юбка, нижняя часть всегда цельная. Это общие шесть слотов, не два независимых каталога.

Верхняя разрешённая граница y=8; поясная зона **y=8…15**, нижняя граница пояса y=16, начало выделения штанин y=24. Есть пиксели в поясной зоне — создаётся отдельный пояс; нет — его нет. Ни high/low в имени, ни отдельного шаблона не нужно. Исключение: «Пояс: no» оставляет верхние пиксели в основной части; «Пояс: yes» требует нарисованный пояс. По умолчанию auto.

Не ограничиваться прежним подолом шорт. Длинный низ помещается в тот же холст; линия пола около y=50 — ориентир, а фактический конец задаёт рисунок до прозрачной границы клетки. Незакрытые части ног остаются кожей. В S/N рисовать обе штанины как часть цельной вещи; оси среднего тела x=32/48, в N анатомическая левая нога справа. В профиле одна видимая штанина с осью x=42; вторую подготовит программа. Пояс/таз/штанины вручную не вырезать.

Юбка ниже пояса не режется на две ноги: ноги продолжают двигаться под цельным нижним модулем. Сложную юбку с особым перекрытием сначала проверить одним образцом; физика ткани не добавляется.

## SHOES — один ботинок, три вида

Клетка **40×18**, опора голеностопа (20,8), PNG **40×54**, S/E/N. Заполнить все три вида одного ботинка. Второй ботинок и W формируются программно. В профиле дальняя обувь/штанина затемняются на 14% как в утверждённой основе; спереди/сзади цвета одинаковы. Утверждённая стопа не меняется: S/N обувь по центру ноги, в профиль пятка на задней линии голени. Не рисовать отдельные носок, пятку и подошву. Размер обуви не растёт с комплекцией.

## Необязательные уточнения ITEMS.md

Обычному PNG не нужны метаданные. Только для исключения добавить строку в ITEMS.md той же папки:

| Файл             | Название  | N    | Пояс | Маска         | Посадка | Материал |
| ---------------- | --------- | ---- | ---- | ------------- | ------- | -------- |
| accessory_01.png | Аксессуар | copy |      |               |         | fixed    |
| hair_01.png      | Причёска  |      |      | hair_mask.png |         |          |
| top_01.png       | Куртка    |      |      | top_mask.png  |         |          |
| bottom_01.png    | Низ       |      | no   |               |         |          |

N=copy/mirror применяется к HEAD S/E/W. Пояс=auto/yes/no — к BOTTOM. Посадка=male/female выбирает исходную посадку TOP, а не меняет пол пользователя. Маска — отдельный PNG в той же папке, с тем же размером/порядком/пустыми ячейками, что у вещи. Ссылки на пути, псевдо-JSON и команды в метаданных не нужны. Маска не является новым предметом каталога и не подключается отдельным слотом.
