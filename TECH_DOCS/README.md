# Технические материалы Creative Factory

Актуальная система персонажей: **[ПЕРСОНАЖ/README.md](ПЕРСОНАЖ/README.md)**.

Персонаж собирается из модульных деталей на одном взрослом риге. A24 — автоматически собранный результат, а не обязательный художественный исходник. Старые эталоны сохранены в [архиве](ПЕРСОНАЖ/АРХИВ_ПРЕЖНИХ_ШАБЛОНОВ/README.md); требования 12 тел и 865 ручных листов больше не действуют.
