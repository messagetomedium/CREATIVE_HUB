# 03. Детали и импорт

Художественные исходники располагаются в `content/art`, реестр частей — `content/avatars/modular/parts.json`. Контракт проверяется `PartEntrySchema` из `apps/web/src/avatar/modular/parts.ts`. Пока реестр дополнительных частей пуст: временная одежда рисуется кодом; четыре причёски подключены отдельным компактным общим атласом. Готовые PNG можно подключать без изменения рига.

PNG детали — вертикальный V4: ширина frameWidth, высота 4×frameHeight, строки N/E/S/W. Отдельные типы не обязаны иметь одинаковый размер. Результат каждой детали автоматически попадает в общий A24. Например, голова 32×128, рукав 6×48, корпус кофты 18×64. Точные примеры входят в комплект.

Дескриптор содержит:

| Поле            | Смысл                                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------------- |
| id / source     | Локальный ID и `/content/name.png`; внешние URL и произвольные пути запрещены                           |
| parent          | head, torso, pelvis, armLeft/Right, legLeft/Right, handLeft/Right, footLeft/Right                       |
| anchor / offset | Опора в исходной клетке и добавочное целочисленное смещение                                             |
| pass            | back или front; конечности накладываются в своей позиции относительно корпуса                           |
| fit             | head/fixed — исходная геометрия; torso/pelvis — ширина из формы тела; limb — две части цепочки суставов |
| material        | skin, hair, top, bottom, footwear, hat, jewelry, special или fixed                                      |
| sync            | head, limb, body, static; отражает привязку и подготовку исходника                                      |
| selection       | Поле конструктора и номер слота; optional gender выбирает набор                                         |
| mirrorWest      | Зеркальное переиспользование правого вида только для действительно симметричных деталей                 |
| overrides       | Замены исходного кадра/смещения для конкретного направления и фазы                                      |
| secondary       | Наследование либо небольшой список фазовых смещений; без физики                                         |

Сначала технически нормализовать PNG: размер клетки, alpha, 5 индексов. Импортер проверяет размеры, нормализует нейтральные оттенки к ближайшему индексу и применяет выбранный материал. Для fixed сохраняет исходный RGBA. Нельзя рассчитывать, что генератор изображения точно воспроизвёл RGB: проверка обязательна.

Для верха передать корпус и левый/правый рукав; для низа — таз и левую/правую штанину; обувь — левая/правая стопа. Это маленькие переиспользуемые части, не полные фигуры. Фиксированную фурнитуру передавать отдельной частью material=fixed. Не вшивать в рукав лишние кисти, в волосы лицо, в обувь брюки.

Для симметричной детали можно переиспользовать PNG/зеркало с разными дескрипторами. Асимметричные родинки, косой пробор и украшения не зеркалятся автоматически. Для юбок/длинных платьев допускаются дополнительные согласованные ключевые изображения.

`ПРИМЕР_ДЕТАЛИ.json` соответствует реальному `РУКАВ_МАСКА_V4.png`; при подключении скопировать PNG в content/art под source именем и дескриптор в реестр. `ПРИМЕР_ИМПОРТА_A24.png` получен тем же механизмом крепления. Не нужно рисовать три версии рукава под три тела.

Переиспользуемые источники хранятся в ограниченном CPU-кэше; в Phaser отправляется только собранный персонаж. Исходники не перезаписываются сборкой. В случае сложного предмета в руке заранее проверить перекрытие пальцами и применить дополнительный проход/маску вместо копии руки в предмете.

У текущего атласа волос 4×4 клетки по 32×32 и опора **(16,19)** внутри клетки, parent=head. У шаблона головы/глаз 32×32 опора **(16,16)**. Это разные координаты художественных исходников на одной и той же голове; не сдвигать сам риг. Зарегистрированные части eyes/mouth отключают соответствующие временные черты, чтобы избежать двойного лица. `ГЛАЗА_ПРИМЕР_V4.png` — готовый маленький пример fixed RGBA.
