# 03. Импорт для разработчика

Художнику достаточно основного ТЗ и PNG-шаблонов. Контракт размеров/опор: `templates.ts`, сгенерированный `ШАБЛОНЫ.json`. Стандарт новых источников — V3 N/E/S, `mirrorWest: true`. Для реальной асимметрии V4 N/E/S/W и `mirrorWest: false`. Не масштабировать готовый PNG руками при интеграции.

Реестр: `content/avatars/modular/parts.json`. Исходник после приёмки размещается в `content/art` и попадает через content build в `/content/<name>.png`. URL только локальный. `PartEntrySchema` проверяет parent, pass, material, размеры, anchor, offset, fit, referenceWidth, mirrorWest/mirrorX, sync, overrides и selection.

`КОМПЛЕКТ_ТЕЛА.json` — готовые шесть записей для четырёх PNG: head, torso, armLeft/Right и legLeft/Right. `selection.field = base, slot = 1` выбирается всегда для общей взрослой базы. Подставить имена фактических PNG в source и скопировать записи в реестр. Тело художника **заменяет** соответствующую болванку, а не накладывается поверх двойной кожи. Цвет material=skin. Контрольный A24 импорта получен этим же композитором.

`fit=torso` с referenceWidth выполняет локальную подгонку плеч/талии/таза по среднему телу и сохраняет шею. `fit=limb` с referenceWidth масштабирует только толщину и использует pivot из anchor; рука движется цельно, нога тоже. `fit=pelvis` подгоняет ширину пояса. Head/fixed сохраняют размер. Для пары конечностей можно сослаться на один PNG двумя записями. mirrorX — отдельное явное отражение конкретного источника, не автоматическое требование ко всем рукам.

Для нового верха использовать дескрипторы top + sleeve; продублировать запись sleeve на другую руку. Аналогично bottom + pant. Выбор selection.field/slot соответствует редактору. Голова base не включает глаза/рот, поэтому eyes/mouth подключаются отдельно. N у лица прозрачный. Кожа/одежда не должны смешиваться в одной перекрашиваемой маске. Базовый реестр пока пуст: новые художественные файлы ещё ожидаются; этот этап исправляет риг/посадку и выдаёт проверяемые шаблоны.

Неперекрашиваемая фурнитура material=fixed — отдельный слой. Особенности кожи/лица material=skin с alpha и соответствующим selection: цвет вычисляется относительно кожи. Для маски на руке использовать тот же parent/fit/anchor, чтобы она следовала за цельной рукой.

Для сложных украшений/длинных волос нужен отдельный back/front слой по согласованному перекрытию. Не обещать автоматический корректный порядок по произвольному рисунку. Обычная причёска V3 имеет прозрачное окно лица и накладывается на голову без вырезания маски кодом; профильное ухо должно оставаться открытым в арте. Старый атлас использует отдельный временный адаптер и не является контрактом новых файлов.
