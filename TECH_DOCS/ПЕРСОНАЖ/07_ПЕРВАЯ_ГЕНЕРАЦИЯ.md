# 07. Первая художественная проработка тела

Референс 1 уже предоставлен: используем крупную округлую голову, короткий корпус/конечности и тонкий пиксельный контур. Конкретного героя, экипировку, фонарь и надписи не переносим. Референс 2 уже применён к четырём женским причёскам.

Следующий художественный проход — универсальный взрослый персонаж без волос, верха и обуви, в отдельных простых чёрных боксерах. Довести светотень/уши/лицо/поверхность тела, не меняя единый риг. Не просить генератор нарисовать заново 24 позы или три разных головы.

1. Взять РИГ.json и ГОЛОВА_V4.png. Геометрия головы 20×20, центр в кадре (24,17); одинаковая у трёх комплекций.
2. Отдельно подготовить детали поверхности головы, рта/глаз/ушей, корпуса, верхних/нижних частей рук/ног, кистей/стоп. Не вшивать соседние части. Боксеры — низ, а не кожа.
3. Нужны N/E/S/W. Для симметричного профиля разрешён mirrorWest, для асимметрии — отдельный рисунок. Лицо на N не рисовать.
4. Использовать пять нейтральных индексов из 04*ЦВЕТ*И_МАСКИ.md и alpha; цвет кожи выбирается программно. Отдельный fixed RGBA только для того, что не перекрашивается.
5. Указать parent, anchor, offset, fit, material, pass, sync; взять ПРИМЕР_ДЕТАЛИ.json как основу, а не копировать его размер 6×12 для всех частей.
6. Провести нормализацию и загрузить комплект через реестр частей. Посмотреть все комплекции, четыре направления, шесть фаз, 10 оттенков кожи и сочетания с четырьмя причёсками.
7. Где автоматическое движение выглядит неестественно, подготовить конкретную дополнительную ключевую позу и overrides, не перерисовывать весь каталог.

Выход: оригинальные небольшие PNG деталей, JSON креплений, исходник художника и автоматически собранные примеры A24. Сначала согласовать один полный образ в движении, затем расширять одежду/черты лица по новым референсам.

Финальную художественную версию тела этот технический этап не объявляет готовой: правила пропорций зафиксированы, программная основа и тестовые волосы доступны для просмотра. Дополнительные пожелания к лицу/светотени можно передать отдельным референсом.
