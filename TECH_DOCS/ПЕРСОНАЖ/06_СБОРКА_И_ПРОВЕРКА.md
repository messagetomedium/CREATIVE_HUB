# 06. Сборка и проверка

```sh
npm run art:build
npm run art:check
npm run typecheck
npm test
npm run test:e2e
npm run export:pages
```

art:build поднимает временный Vite на 5199, использует реальный браузерный композитор и завершает сервер. Нужен Chromium (системный либо установленный Playwright). Результаты — здесь: пустые V3, подложки, схемы, ШАБЛОНЫ.json, КОМПЛЕКТ_ТЕЛА.json, manifest.json, РИГ.json, ЗАМЕРЫ.json. A24 — только автоматическая проверка разработчика, художнику не требуется. Художественный оригинал причёсок не перезаписывается. Для нормализации нового художественного файла можно использовать normalizeMask или подготовщик; Python-скрипт использовался для первоначальной технической подготовки, но игра/обычная art:build от Python/Pillow не зависят.

## Проверить визуально

В конструкторе: сравнить три комплекции, не меняя причёску/направление; голова и волосы не меняют размер. Проверить четыре ракурса, idle/walk, цвета и сохранение. «Проверка графики» переключает 1× / Крупно / A24. Затем войти на завод и пройти WASD/стрелками. Проверять отсутствие щелей суставов, прыжков головы и удвоенной кожи.

Для импортного комплекта из четырёх PNG проверить, что болванка заменяется, голова одинакова у комплекций, шея остаётся с корпусом, руки цельные, ноги не сгибаются и не расходятся. Для рукава проверить профиль: дальняя рука за корпусом, ближняя перед ним. Первые две причёски проверяются также на отсутствие обрезания пучков в дыхании и зеркальность профилей. Для сложной детали задать overrides и проверить только исправленную позу. Для лицевых масок проверить N, где маска должна быть пустой.

## Производительность

Атлас волос — 128×128 RGBA, содержит 16 статических видов; на GPU не создаются отдельные волосы/части. A24 — 288×256, 294912 байт RGBA на выбранный вариант. Кэш A24 ограничен **8** вариантами (2359296 байт RGBA ≈2.25 MiB), кэш исходных деталей — 32 файла. Ревизия сохранения не вызывает отдельную сборку той же внешности. Ходьба/поворот выбирают кадры готовой текстуры.

Реальные локальные измерения 50 комбинаций и 100 повторных запросов записаны в `ЗАМЕРЫ.json`. Это время CPU-сборки headless Chromium и размер конкретного кэша, **не** FPS, общая память браузера, нагрузка многопользовательского сервера или доказательство ускорения относительно прежней реализации. Сравнительного замера старого варианта нет.

## Что автоматизировано

Риг/взрослая миграция/палитры/валидация частей — unit/integration; редактор/сохранение/игра/направления/кэш/одинаковая голова — браузерные сценарии. art:check проверяет актуальные размеры/голову/точки/соответствие атласа. Геометрическая автоматизация не заменяет художественный просмотр.

## Ограничения

Независимой физики волос, моргания и эмоций пока нет. Первые четыре женские причёски — художественный тест на техническом теле, не финально утверждённый персонаж. Дополнительные категории сохраняют слоты, но не считаются нарисованными по одному факту наличия кнопки. Возможны дальнейшие ручные поправки движения/посадки после вашего визуального теста.

В Supabase применить `202610270002_adult_avatar_rig.sql` после прежних миграций: он превращает старые child в adult и запрещает новые child на сервере, сохраняя остальные поля. В браузере старые записи также нормализуются без потери настроек. Роли/RLS/Email OTP этим графическим этапом не меняются.
