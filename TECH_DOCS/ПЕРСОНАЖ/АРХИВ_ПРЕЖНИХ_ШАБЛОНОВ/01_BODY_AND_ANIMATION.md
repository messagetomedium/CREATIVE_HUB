# ТЗ 01. Тело, сетка и анимации

Основа — [REF_BODY_MASTER_A24.png](REF_BODY_MASTER_A24.png), а не увеличенная схема GUIDE. Один выбранный персонаж и все его слои занимают одинаковый холст.

## 1. Формат и ракурс

| Параметр              | Требование                                                                                                                |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Проекция              | 3/4 top-down: вертикальный персонаж, немного видны верх головы/плеч. Ортогональная карта, без изометрии                   |
| Исходный файл         | PNG RGBA, 8 бит на канал, прозрачный фон, sRGB. Также исходник художника с редактируемыми слоями                          |
| Один кадр             | **48×64 px**                                                                                                              |
| Основной лист A24     | **288×256 px**, 6 колонок × 4 строки, 24 позиции                                                                          |
| Голова/волосы V4      | **48×256 px**, 1 колонка × 4 строки, 4 вида с нейтральной высотой головы                                                  |
| Опора                 | **x=24, y=56** от левого верхнего угла каждого кадра; центр на полу между стопами                                         |
| Padding / spacing     | **0 / 0**; не обрезать прозрачные поля, не паковать/не поворачивать кадры                                                 |
| Направление координат | +X вправо, +Y вниз; нумерация кадров с нуля                                                                               |
| Масштаб               | Рисовать в 1×. При просмотре 4×/8× — nearest neighbour, без размытия                                                      |
| Пиксельный стиль      | Чёткие пиксельные края; обычные контуры непрозрачные, снаружи alpha=0. Частичная прозрачность допустима у кожных эффектов |
| Свет                  | Единый мягкий свет сверху-слева экрана; не менять его между вариантами                                                    |
| Поля                  | Силуэт не должен касаться границ кадра. Рекомендуемая рабочая область x=2…45, y=2…57; место ниже ног оставить прозрачным  |

Не рисовать в PNG падающую тень на полу, сцену, рамку, сетку, цифры, имена, точки крепления. Обувь, волосы, лицо и украшения не вшивать в тело. Манекен анатомически нейтрален, без интимных деталей; финальная стилизация тела следует тем же контрольным точкам.

## 2. Раскладка A24 — не переставлять

| Строка | Y   | Направление | Что видно                        | Номера кадров |
| ------ | --- | ----------- | -------------------------------- | ------------- |
| 0      | 0   | north / N   | Спина, затылок                   | 0–5           |
| 1      | 64  | east / E    | Профиль, персонаж смотрит вправо | 6–11          |
| 2      | 128 | south / S   | Лицо, персонаж смотрит к зрителю | 12–17         |
| 3      | 192 | west / W    | Профиль, персонаж смотрит влево  | 18–23         |

| Колонка | X   | Фаза   | Положение                                                  |
| ------- | --- | ------ | ---------------------------------------------------------- |
| 0       | 0   | idle-0 | Основная нейтральная поза                                  |
| 1       | 48  | idle-1 | Голова/торс на 1 px выше, стопы сохраняют опору            |
| 2       | 96  | walk-0 | Проходная нейтральная поза                                 |
| 3       | 144 | walk-1 | Одна нога/рука выдвинуты, противоположная сторона отведена |
| 4       | 192 | walk-2 | Проходная нейтральная поза                                 |
| 5       | 240 | walk-3 | Обратная фаза относительно walk-1                          |

Ожидание: колонки **0,1**, цикл **2 кадра/с**. Ходьба: **2,3,4,5**, цикл **9 кадров/с**. Это четыре рисованные фазы шага; не 9 отдельных рисунков. Одинаковые проходные позы можно повторить, но все ячейки обязаны присутствовать.

Главная опора (24,56) неподвижна, отдельная стопа может приподниматься в шаге. Хитбокс движения 20×16 не является размером картинки и не меняется от телосложения/возраста. Не передвигать весь слой на глаз, чтобы «встали ноги».

## 3. Двенадцать тел

Четыре варианта пола/возраста × три телосложения:

| Кнопка редактора | Технические поля | Доступные тела        |
| ---------------- | ---------------- | --------------------- |
| Мальчик          | male / child     | slim, average, sturdy |
| Девочка          | female / child   | slim, average, sturdy |
| Женщина          | female / adult   | slim, average, sturdy |
| Мужчина          | male / adult     | slim, average, sturdy |

`slim` = худое, `average` = среднее, `sturdy` = плотное. Все 12 `RIG_*.png` приложены. Это варианты посадки одного каталога; одинаковые по пикселям элементы можно повторно использовать через manifest.

У одного возраста голова имеет общие точки для всех полов/телосложений. Поэтому одна подгонка глаз/рта/головного убора на возраст подходит всем шести телам этого возраста. Мужские и женские наборы причёсок различаются стилями, а не положением головы.

Взрослая болванка: центр головы в нейтральной фронтальной позе **(24,17)**. Детская: **(24,22)**. В правом профиле центр X=25, в левом X=23. Детские шаблоны уже построены меньше (исходные пропорции 0.9 по ширине / 0.86 по высоте и целочисленная привязка). **Не масштабировать детский PNG повторно в приложении.** Для точных точек брать JSON, а не проценты.

Силуэт/штриховку можно художественно проработать внутри габаритов. Положение головы, шеи, плеч, кистей, таза и стоп должно соответствовать шаблону: иначе все подогнанные элементы придётся переделывать. Сначала проверить один полный комплект на основном теле, затем подгонять остальные тела.

## 4. Контрольные точки и V4

В [CF_BODY_CONTACTS.json](CF_BODY_CONTACTS.json) для каждой ячейки есть `headCenter`, `neck`, `shoulderLeft/Right`, `handLeft/Right`, `hipLeft/Right`, `footLeft/Right`, `anchor`, `headOffsetY`. Все значения локальны в кадре, а не на целом листе. Left/Right — две стороны шаблона до отражения профиля, не указание художнику зеркалить асимметричные детали.

Для V4 те же четыре строки N/E/S/W, каждая 48×64. Деталь рисуется относительно **idle-0** соответствующего тела: полный прозрачный кадр, не маленький вырез вокруг причёски/лица.

При разворачивании V4 в A24 для каждого ракурса и каждой колонки:

```text
исходная область = (0, row*64, 48, 64)
целевой кадр = (column*48, row*64, 48, 64)
смещение рисунка внутри целевого кадра по Y = [0, -1, 0, -1, 0, -1][column]
смещение по X = 0
```

Каждый кадр отдельно обрезается его границами. Таблица одинакова для обоих возрастов после округления. Не двигать V4-деталь на -1 внутри исходника: подъём добавляет подготовщик ровно один раз. Приложены примеры одновременно в V4 и A24, чтобы проверить результат вручную.

Длинные волосы/шапка в этом этапе следуют голове без дополнительных собственных колебаний. Глаза/рот не требуют отдельных циклов моргания/речи. Для асимметричной родинки, пробора или украшения рисовать левый и правый виды отдельно: автоматическое отражение может поменять сторону детали.
