# ТЗ 03. Поставка и проверка

## Порядок работы художника

1. На `male-adult-average` нарисовать финальное тело во всех 24 позициях, не меняя точек из JSON. Для согласования приложить 1× и увеличенное nearest-neighbour изображение.
2. Проверить на этом теле один комплект верха/низа/обуви и одну причёску, глаза, рот, веснушки, румянец. Открыть все слои одновременно без ручных сдвигов. Техническая контрольная сборка уже дана в `CF_REFERENCE_STACK.ora`.
3. Утвердить единый стиль остальных тел/пропорций, затем подогнать тело и одежду на остальные RIG. Не рисовать весь гардероб до проверки одной полной сборки.
4. Выполнить шесть согласованных вариантов каждой категории, 12 причёсок в двух наборах, шесть названных особенностей лица. Сюжеты ещё не назначенных особенностей тела/особых предметов сначала согласовать отдельно.
5. Подготовить мини-иконки и manifest; отметить покрытие всей матрицы `CF_PRODUCTION_LIST.csv`, включая переиспользуемые/пустые проходы.

## Файлы поставки

В этой задаче все ТЗ/эталоны — в корневой **TECH_DOCS без подпапок**. Художественную поставку также можно сложить плоско, используя имена из CSV:

```text
body_male-adult-average.png
top_01_male-adult-average_main.png
bottom_01_male-adult-average_main.png
shoes_01_male-adult-average_main.png
hair-female_01_adult_back.png
hair-female_01_adult_front.png
face-feature_01_adult_main.png
hat_01_adult_hair-keep.png
icon_top_01.png
```

В имени тело описывает посадку, а не уникальное имя пользователя. Внешние URL/скрипты, пути с `..`, SVG от сторонних источников не принимаются. Оригиналы PSD/Aseprite/ORA художника остаются редактируемыми; игровые PNG не должны требовать открытия исходника для просмотра.

Manifest — JSON с версией `cf-avatar-art-1`, форматом `A24/V4/ICON`, category/slot/rig/pass/material, локальным PNG-путём. На каждую строку максимальной матрицы явная ссылка на файл, alias на идентичный файл или `null` для пустого прохода. `null` допустим только у необязательных back/front/неиспользуемого вида, не вместо отсутствующего тела/верха/низа/обуви/запрошенного варианта. Пустая строка N в V4 лица — часть PNG, не отсутствие всего листа.

Окрашиваемая ткань/кожа/волосы — нейтральные бело-серые RGBA-маски. Тон берёт приложение: RGB маски умножается на выбранный цвет, alpha сохраняется. Светлый участок 255 даёт исходный цвет, 220 — лёгкую тень, 180 — более глубокую. Не использовать сплошной чёрный для границы кожи, если он не должен оставаться чёрным при любом оттенке. Неокрашиваемый цветной декор — отдельный `_fixed` той же раскладки, не новый пользовательский слот.

Не экспортировать 10/12 цветных копий. Не делать атлас с автоматическим trimming, rotation, extrude или промежутками. Не сохранять текст/сетку в PNG. Для кожных эффектов проверять частичную alpha на прозрачном фоне, а не белой подложке.

## Чек-лист приёмки

- [ ] A24 ровно 288×256, V4 ровно 48×256, иконка ровно 48×48; канал alpha присутствует.
- [ ] Ряды строго N/E/S/W. Ожидание 0,1; ходьба 2,3,4,5. Ни один кадр не переставлен.
- [ ] Опора всех тел (24,56). Голова, плечи, кисти, таз и стопы совпадают с RIG/JSON по фазам.
- [ ] Штаны/обувь/рукава действительно идут с конечностями, а не с одной неподвижной позой.
- [ ] V4 совпадает с idle-0 и после разворачивания не получает двойной bob.
- [ ] На N нет глаз/рта/пятен лица; асимметричная родинка сохраняет сторону.
- [ ] Одежда не содержит тело, шапка не содержит волосы, веснушки не содержат лицо/фон.
- [ ] Все 10 тонов кожи и 12 тонов волос/ткани проверены; эффект кожи не выглядит отдельной наклейкой другого оттенка лица.
- [ ] Все 12 тел покрыты; одинаковые элементы могут делить файл, но ни одна совместимость не подразумевается молча.
- [ ] Волосы не пробивают шапку: hair-keep проверена на всех 12 стилях данного возраста.
- [ ] Несколько кожных эффектов одновременно и сочетания верх/низ/обувь не создают дубликатов частей тела.
- [ ] Контур укладывается в кадр на каждой фазе; на соединениях не появляется чужих пикселей из соседнего кадра.
- [ ] Отдельно проверены 85 небольших иконок, без полноразмерного персонажа/текста/рамки.
- [ ] Указаны автор, дата, права/разрешение использования и источники при наличии. WorkAdventure/другие игры не используются как источник кода/картинок.

## Проверка приложенного технического комплекта

`node scripts/check-avatar-tech.mjs` проверяет PNG/прозрачность/размеры, отсутствие подпапок, 12 RIG, палитры, 865 строк матрицы и наличие контрольных точек на 24 кадра каждого тела. Эталоны проверяются отдельно от финальной художественной приёмки: программа не может оценить анатомию/красоту дизайна.

Воспроизведение эталонов: запустить `npm run dev`, затем `node scripts/export-avatar-tech.mjs http://127.0.0.1:5173`. Генератор использует фиксированные координаты и палитры текущего проекта, сохраняет результат прямо в TECH_DOCS. Схемы проверялись визуально; шаблоны не являются генеративными иллюстрациями с приблизительной сеткой.
