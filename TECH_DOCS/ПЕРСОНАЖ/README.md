# Creative Factory — модульный персонаж

27 октября 2026. Этот комплект заменяет прежнее ТЗ на ручные A24 для каждого предмета и телосложения.

Один взрослый риг → выбранные детали и цвета → программные позы → **один A24 288×256**. Редактор и Phaser используют один композитор. Карта, коллизии, скорость движения и игровые механики не меняются.

## Что создаёт код

Голова/уши/шея, корпус/таз, руки/кисти, ноги/стопы; узлы суставов, локальные размеры трёх комплекций, маски/контуры, временная одежда из тех же частей и шесть фаз движения. Это воспроизводимая основа и техническая поверхность, не окончательно утверждённая художественная анатомия.

## Что подготовлено по референсу

Четыре женские причёски: два пучка с чёлкой, высокий пучок, две косы, каре с чёлкой. Оригинальная интерпретация по предоставленному референсу создана с помощью инструмента генерации изображения; сохранён исходник. Техническая подготовка выполнена отдельно: nearest-neighbour до 128×128, индексирование пяти тонов, alpha 0/255, удаление фрагмента косы, попавшего из соседней строки. Набор занимает один маленький общий PNG, а не отдельные листы ходьбы.

`ПРИЧЕСКИ_ИСХОДНИК.png` — редактируемый художественный ориентир. `ПРИЧЕСКИ_ИНДЕКСЫ.png` — точная копия игрового индексированного атласа. Финальную оценку сходства/качества выполняем визуально; нормализация сама по себе не гарантирует художественное качество.

## Шаблоны

- `ПРОПОРЦИИ_ТЕЛА.png`, `ТЕЛО_*_A24.png`: одна геометрическая модель в трёх комплекциях, в чёрных боксерах; без верхней одежды, волос и обуви. Боксеры — отдельный нижний слой.
- `КОРПУС_БАЗА_V4.png`, `РУКА_БАЗА_V4.png`, `НОГА_БАЗА_V4.png`, `ШЕЯ_БАЗА_V4.png`, `ТАЗ_БАЗА_V4.png`, `КИСТЬ_БАЗА_V4.png`, `СТОПА_БАЗА_V4.png`: нейтральные индексированные шаблоны раздельных частей. Их fit и parent определяют посадку, не пол/комплекция. `СУСТАВЫ_A24.png` показывает точки по фазам.
- `ГОЛОВА_V4.png`: общая голова для всех комплекций, 32×128; клетки 32×32.
- `ВЕРХ_КОРПУС_V4.png`, `РУКАВ_МАСКА_V4.png`, `ШТАНИНА_МАСКА_V4.png`: реальные примеры для импортера. Вторая половина конечности следует отдельному суставу.
- `ПРИМЕР_ДЕТАЛИ.json`, `ПРИМЕР_ИМПОРТА_A24.png`: дескриптор рукава с ручным исключением позы и результат именно этого компилятора.
- `ПУСТАЯ_ДЕТАЛЬ_V4.png`, `ИНДЕКСЫ_МАСКИ.png`: стартовый прозрачный холст и пять точных серых индексов.
- `ПРИЧЕСКА_1…4_СБОРКА_A24.png`: собранные примеры причёсок на общей основе.
- `РИГ.json`: точки всех 72 технических поз (3 комплекции × 4 направления × 6 фаз), размеры/палитры.
- `manifest.json`, `ЗАМЕРЫ.json`: описание экспорта и воспроизводимый результат локального измерения.

## Что передавать для новых элементов

Один комплект PNG частей в нейтральной индексированной палитре, отдельный фиксированный RGBA-декор при необходимости, JSON креплений/выборов, описание референса и авторства. Не нужны цветные копии, отдельные версии на каждую комплекцию или 24 ручных фазы. Для сложного фасона разрешены конкретные ключевые исключения вместо усложнения всего рига.

Запуск одной командой: `npm run art:build`. Она поднимает временный локальный сервер, собирает примеры и завершает его. `npm run art:check` проверяет актуальный комплект. В игре: конструктор → Женщина → Голова → одна из первых четырёх причёсок → сохранить → завод. Проверка графики в предпросмотре даёт 1×, увеличение и A24.

Исторические материалы не потеряны: [АРХИВ*ПРЕЖНИХ*ШАБЛОНОВ](АРХИВ_ПРЕЖНИХ_ШАБЛОНОВ/README.md). Они не участвуют в сборке и не задают действующие размеры частей.
