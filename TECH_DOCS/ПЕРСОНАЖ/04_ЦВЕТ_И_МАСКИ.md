# 04. Палитры и маски

Выбран **palette swap**: он сохраняет фиксированный тонкий контур, блик, базу и две тени при любом выбранном оттенке. Прежнее multiply оставлено только для совместимости с legacy layered-sheets, но не используется для новых модульных частей. Multiply умножает и контур/фурнитуру, поэтому для нашего управляемого набора материалов менее удобен.

| Индекс RGB    | Роль                                    |
| ------------- | --------------------------------------- |
| #202020 (32)  | Постоянный контур #352b35               |
| #505050 (80)  | Глубокая тень: 48% смеси базы с #382b3a |
| #808080 (128) | Полутень: 22% смеси базы с #573d42      |
| #b8b8b8 (184) | Выбранный базовый цвет                  |
| #f0f0f0 (240) | Блик: 30% смеси базы с #fff3dc          |

PNG RGBA, alpha=0 снаружи, 255 на обычных пикселях, без сглаживания/подложки. Для тонких кожных эффектов допустима частичная прозрачность; в faceFeatures/bodyFeatures импортер сохраняет её, а не порогует. Для однотонной маски эффекта использовать базовый индекс #b8b8b8 и alpha, material=skin: краска будет skin-relative, а не обычная кожа. Пять индексов показаны в `ИНДЕКСЫ_МАСКИ.png`. Ближайшее квантование нейтральной маски выполняет normalizeMask; непрозрачные цветные пиксели сначала проверить вручную, а не считать произвольную картинку хорошей маской.

Материалы независимы: Skin, Hair, Top, Bottom, Footwear, Hat, Jewelry, Special. Металл/камни/принт, не подлежащие перекраске, идут отдельным RGBA material=fixed. Не создавать 10/12 цветных копий одного предмета.

Кожа (10): #f4e3d4, #efd7c6, #e8c8a2, #e2bfae, #dcae86, #bd947f, #ad8261, #9a7767, #805d48, #674e43.

Волосы (12): #273a36, #594035, #78543c, #a8784f, #c79e68, #e2c78f, #e9dccc, #b7afa7, #797679, #b75b3f, #8d393b, #5b494c.

Ткань/обувь/детали (12): #f1e9d8, #d9cbbc, #d6ab82, #cf6546, #e49a83, #ccac62, #7c9585, #46584c, #7495a9, #6e7da4, #a294bd, #484754. Каждый блок хранит свой выбранный цвет.

Веснушки/родинки/покраснения/тени под глазами/румянец/переносица рисуются относительно головы. Цвет эффекта смешивается с выбранной кожей, интенсивность задаётся alpha. Временные процедурные эффекты уже следуют голове; окончательные художественные маски можно заменить импортом. На спине глаз/рта/лицевых эффектов нет.

После подготовки проверить все 10 тонов кожи, 12 волос и 12 ткани. Пять уровней исходника должны оставаться различимыми, контур — одинаковым, RGB под прозрачностью не должен давать цветной ореол. Цветная копия генерации не является готовой перекрашиваемой маской без нормализации и просмотра.
