# 02. Риг v2

Художник сдаёт только статический V3 N/E/S из основного ТЗ. Риг формирует W и A24: N/E/S/W × idle0,idle1,walk0,walk1,walk2,walk3, 2/9 fps. Композиция происходит при смене внешности; проигрывание выбирает готовые кадры.

В idle движется только голова на 1 px; шея принадлежит корпусу. Волосы/глаза/рот/головные аксессуары наследуют голову. В ходьбе корпус/голова поднимаются на 1 px в проходных фазах. Рука — одна жёсткая деталь с кистью: в профиле поворот около плеча ±14°, во фронте/сзади попеременные вертикальные смещения ±1 px. Нога со стопой остаётся вертикальной: поднимается целиком на 2 px под таз; нет сгиба коленей, бокового разведения или горизонтального маха. Центры ног плотного тела сближены до 19/29.

Точки `joint` сохранены для совместимости/диагностики, но находятся на прямой root–end и не являются границами художественных модулей. `handLeft/Right` — точки крепления предметов на конце цельной руки, а не отдельные кисти.

Импортная рука семплируется жёстким целым вокруг опоры, без сглаживания; ноги только перемещаются. В профиле дальняя рука за корпусом, ближняя перед ним. Ручные overrides остаются для исключений. Физика волос, моргание и сложные юбки не добавлены.

Текущий тестовый атлас волос имеет поправки посадки по слоту/ракурсу в `hair.ts`: это компенсация неточного прежнего исходника. W использует зеркальный E. Новые художественные V3 используют общую опору (16,16), без этих частных поправок.
