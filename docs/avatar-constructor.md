# Конструктор персонажа

Внешность/анимация редактора **01432c7 утверждены** и не меняются. Две взрослые модели, четыре комплекции, постоянные голова/кулачки/обувь, контур 2 px, прямые руки/ноги 26/26. Ожидание 500/500 мс, ходьба 125/175/125/175 мс, голова при ходьбе неподвижна. UI, направления поворота, слоты, палитры и сохранение прежние.

30 октября художественное производство сведено к [пяти макетам](../TECH_DOCS/README.md): HAIR, HEAD, TOP, BOTTOM, SHOES. Простые PNG автоматически проходят CLI → ракурсы → внутренние модули → подгонка → существующие слоты. Цельный TOP включает рукава, bottom не требует отдельных штанин или обозначения длины, skirt сохраняет цельную нижнюю часть. Старые варианты исходников читаются для совместимости, но художнику не предлагаются.

Достраивание видов основано на прозрачности ячеек. Для S/E/W головной детали N зеркалится из S или копируется по необязательному ITEMS. Глаза/рот/лицевые эффекты только фронтом с профильной адаптацией. Авторские N/W сохраняются; вся фигура не зеркалится. Волосы и сложный верх могут уточняться технической маской, без обязательных метаданных обычной вещи.

Новые компоненты заранее подгоняются отдельным адаптером; утверждённые renderer/позы остаются неизменными и запекают прежние кадры. Особенности тела и предметы в руках исключены только из текущей художественной поставки; пункты редактора, старые PNG и сохранения не удалены. AvatarConfig/catalogVersion/RLS не меняются. Подробности — [инженерный контракт](character-engineering.md).

Завод сохраняет прежнюю основу и физику; для новой графики выбран совместимый контекст подгонки. Это не новый риг карты и не мультиплеер. Перед серийной работой художника — [проверка одного комплекта](../TECH_DOCS/CHARACTER/DELIVERY.md).
