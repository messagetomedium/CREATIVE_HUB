# Готовые PNG для персонажа

[Начать с пяти макетов](../TECH_DOCS/README.md) · [Скачать ZIP](../TECH_DOCS/CHARACTER/CREATIVE_FACTORY_ARTIST_KIT.zip) · [Правила/маски](../TECH_DOCS/CHARACTER/ART_RULES.md).

Взять один TEMPLATE: HAIR, HEAD, TOP, BOTTOM или SHOES. Рисовать цельную вещь на новом слое; подложку скрыть и экспортировать полный PNG на прозрачности. Контур 2 px, без сглаживания. Рукава/штанины/слои волос и анимацию вручную не вырезать.

| Папка         | Простые имена                                                |
| ------------- | ------------------------------------------------------------ |
| hair          | hair_01.png, при необходимости hair_f_01.png / hair_m_01.png |
| eyes          | eyes_01.png                                                  |
| mouth         | mouth_01.png                                                 |
| face_features | face_01.png                                                  |
| tops          | top_01.png — вся одежда с рукавами                           |
| bottoms       | bottom_01.png или skirt_01.png, общие номера 01…06           |
| footwear      | shoes_01.png — один ботинок S/E/N                            |
| hats          | hat_01.png                                                   |
| jewelry       | accessory_01.png — голова/верхняя шея                        |

У первых четырёх макетов ячейки S/E/N/W. У SHOES только S/E/N одного ботинка. Для обычной вещи достаточно одного PNG; исключения N/пояса/посадки/маски задаются необязательной строкой ITEMS.md. Маска лежит в той же папке и не является новым слотом.

Попросить Codex: **«Импортируй новые PNG из CHARACTER»**. Команда `npm run character:import` проверяет размер/палитру/alpha, достраивает разрешённые виды, готовит детали/подгонку и миниатюру. Оригиналы не изменяются, ошибочная замена сохраняет последнюю рабочую версию; причина появится в DEBUG_REPORT.md. Затем проверить один образ в редакторе, сохранение/reload и публикацию.

Папки body_features и specials остаются для совместимости существующей программы и сохранений, но в новое художественное производство не входят. Их прежняя функциональность не удаляется. Само тело/движение редактора 01432c7 не меняются при импорте вещей.
