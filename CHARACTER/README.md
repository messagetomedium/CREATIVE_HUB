# Художественные исходники персонажей

Сюда загружаются только **готовые PNG на прозрачности** и пояснения к ним. [Начать с TECH_DOCS](../TECH_DOCS/README.md): взять шаблон 2×, рисовать отдельным слоем, скрыть техническую подложку, экспортировать в исходном размере.

Категории: hair, eyes, mouth, face_features, body_features, tops, bottoms, footwear, hats, jewelry, specials. Названия и размеры: [FILE_NAMING](../TECH_DOCS/CHARACTER/FILE_NAMING.md), [таблица шаблонов](../TECH_DOCS/CHARACTER/README.md).

Примеры: `hair/hair_long_full_01.png`, `bottoms/pants_high_full_01.png`, `footwear/shoes_basic_pair_01.png`. Низ и причёска рисуются целиком, глаза/рот/лицевые накладки только фронтом. Для верхних деталей общий шаблон details. Режимы и порядок видов — в TECH_DOCS; номер соответствует общему слоту категории 01…06 (особенности тела до 12). Внутри низа pants/skirt/shorts не имеют раздельной нумерации слотов. JSON и ручная подготовка частей рига не нужны.

После загрузки попросить Codex **импортировать новые изображения из CHARACTER**. Команда `npm run character:import` проверяет и подключает их; затем разработчик проверяет приложение и публикует обновление. Сам коммит PNG без этой команды пока не меняет игровой каталог.

Оригинальные PNG не изменяются импортом. Рабочие текстуры, отражения и миниатюры создаются отдельно. `DEBUG_REPORT.md` заполняет Codex только для критических ошибок; исправить названный файл и повторить импорт. При успешном исправлении запись исчезнет. Не загружать технический TEMPLATE как готовый рисунок.

Тело и анимационные фазы художнику рисовать не нужно. Сейчас папки подготовлены для будущей графики, новые коллекции сюда не добавлялись.
