# tops — исходники художника

Шесть комплектов. Body + один sleeve с одним номером; безрукавка без sleeve, glove необязателен. Рукав 24×40 на ракурс. Для облегающего женского корпуса доступна альтернативная подложка top_female.

Утверждённый комплект — [TECH_DOCS](../../TECH_DOCS/CHARACTER/README.md), [имена](../../TECH_DOCS/CHARACTER/FILE_NAMING.md), [порядок сдачи](../../TECH_DOCS/CHARACTER/DELIVERY.md). Контур 2 px. Сначала один тестовый вариант; старый импортёр ещё не адаптирован к этому комплекту.
